# Verzuimstandaard – Werkgevers – Verzekeraars/Volmachten

Deze repository bevat de documentatie en releases voor de Verzuimstandaard **Werkgevers – Verzekeraars/Volmachten** 

## Doel

Dit koppelvlak ondersteunt de elektronische gegevensuitwisseling tussen Verzekeraars/Volmachten.

## Releases

SIVI publiceert releases van dit koppelvlak via GitHub Releases.

Arbodiensten ondersteunen de actuele versie en de twee versies ervoor tot maximaal de laatste major release. Dat betekent dat per 1 januari 2027 de volgende versies de actuele versies zijn: 2024, 2025 en 2026. 

Een publicatie bestaat uit:

- releasenotes;
- toelichting op het koppelvlak;
- functionele beschrijvingen van het verzuimbericht;
- een ZIP-bestand met de bijbehorende XSD;
- een ZIP-bestand met de volledige release.

## Releasevergelijking

De functionele beschrijvingen zijn ook als Markdown beschikbaar in deze repository. Hierdoor kunnen wijzigingen tussen verschillende releases via GitHub worden vergeleken.

De XSD-bestanden staan ook in de repository zodat technische wijzigingen tussen releases zichtbaar zijn.

## Algemene documentatie

Documentatie die voor meerdere koppelvlakken geldt, staat centraal in de repository **Verzuimstandaard**. Het gaat nu om de koppelvlakspecificaties.

## Vragen en wijzigingsverzoeken

Neem voor opmerkingen of vragen contact op met SIVI. In GitHub kan dat via de repository **Verzuimstandaard**.

## Beheer

SIVI beheert de Verzuimstandaard.

Alleen SIVI kan wijzigingen aanbrengen in de officiële standaard.
